### 💡 What I care about

- 🎨 **Design ↔ code continuity**: I work on both sides, so what's validated in Figma is what ships, tokens, states and variants included.
- ♿ **Accessibility first**: semantic HTML, keyboard navigation, WCAG guidelines, and interfaces that still work on a cheap phone with a bad connection.
- 🧱 **Reusable foundations**: UIs built from composable, documented components rather than one-off pages.
- 🌐 **Web standards**: understanding what the platform does natively before reaching for a library.

#### 🌊 [Orisk](https://orisk.app)
**Civic tech for water monitoring in Guadeloupe**

Real-time map of water outages, leaks and scheduled cuts across all 32 municipalities (4,782 mapped locations). Designed and built solo, from Figma to production.

- ~45k lines of code · 30 screens · 13 API routes
- Mobile-first **offline PWA** for low-coverage areas
- **Privacy-by-design**: no account, anonymous reports, scheduled purges
- Geospatial reference data from public sources (IGN, BAN, ARS)
